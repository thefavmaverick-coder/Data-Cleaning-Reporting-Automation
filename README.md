# Data Cleaning & Reporting Automation Using Excel

An Excel-based data cleaning and reporting project focused on improving data quality, standardizing business information, handling missing values, and preparing structured datasets for reporting and analysis.

---

## Project Overview

This project demonstrates practical data cleaning and reporting techniques using Microsoft Excel.

The project uses a business sales dataset containing transaction dates, client information, departments, regions, payment methods, revenue, profit, and profit margin.

Various Excel tools, formulas, and built-in features are used to clean and organize the dataset, improve consistency, and prepare the information for reporting.

## Project Objectives

- Clean and organize raw business data.
- Identify and handle missing values.
- Remove duplicate records.
- Standardize text and formatting.
- Apply Excel formulas for data preparation.
- Improve spreadsheet readability and structure.
- Prepare cleaned data for reporting and analysis.

## Dataset Overview

The dataset contains business-related information with the following columns:

| Column | Description |
|---|---|
| Date | Transaction or record date |
| Client | Client or company name |
| Contact | Contact person |
| Department | Business department |
| Region | Geographical region |
| Payment | Payment method |
| Revenue | Revenue amount |
| Profit | Profit amount |
| Profit Margin | Profit-to-revenue calculation |

**Dataset Information:**
- Original records: 28
- Business data fields: 9
- Data format: Excel Workbook (.xlsx)

## Tools Used

## Data Cleaning Techniques

The following Excel techniques were covered and applied during the data-cleaning exercise.

| No. | Technique | Purpose |
|---:|---|---|
| 1 | Autofit Rows and Columns | Adjust row heights and column widths |
| 2 | Find & Replace | Find and replace selected values |
| 3 | LOWER & UPPER | Standardize text capitalization |
| 4 | TRIM & PROPER | Remove extra spaces and format text |
| 5 | Text to Columns | Separate combined text into individual columns |
| 6 | Remove Duplicates | Identify and remove duplicate records |
| 7 | Fill Empty Cells | Handle missing values |
| 8 | IFERROR | Handle formula errors |
| 9 | Formatting | Improve data presentation and readability |
| 10 | Remove Gridlines | Create a cleaner worksheet layout |

## Data Preparation

The cleaning process focuses on:

- Reviewing the dataset structure.
- Identifying blank and inconsistent values.
- Standardizing text entries.
- Removing duplicate records.
- Applying formulas where required.
- Organizing columns and formatting.
- Preparing the cleaned workbook for further reporting.

## Key Learning Outcomes

- Practiced data cleaning using Microsoft Excel.
- Improved text consistency using Excel functions.
- Learned to identify and handle duplicate records.
- Worked with missing values and formula errors.
- Used Text to Columns for data separation.
- Improved spreadsheet formatting and organization.
- Understood the importance of data preparation before reporting.

## Conclusion

This project demonstrates the importance of data cleaning and preparation in business reporting using Microsoft Excel. By applying built-in Excel tools, formulas, and formatting techniques, raw business data can be transformed into a more consistent and organized format.

The project provides a foundation for developing structured reports and visual summaries that support better data understanding and business analysis.
